# User testing results — November 17, 2026

Three testers tried the core task on https://giftwise-fawn.vercel.app. They gave feedback in English; the notes below are paraphrased from the student's notes, not verbatim transcripts.

| Tester | Feedback (paraphrased) | Theme |
| --- | --- | --- |
| 1 | The site is really good and helps find things they want, but the variety could be richer and it could give more inspiration. | More variety · inspiration |
| 2 | The site is really good, but the UI could be clearer, and the price comparison after clicking could be more obvious. | Clearer UI · prominent comparison |
| 3 | When unsure what they want at the start, they'd like more inspiration, such as a page of recommendations to browse first. When they already know what they want, it should be more focused. | Browse-first entry · focused path |

## Agent walkthrough (phone + desktop, before testing)
- Fixed before testing: refining gave no visible confirmation; refine box hard to find on phones.
- Open: one AI reason invented a detail the shopper never gave ("knees"); "more practical" dropped one of the stated interests; some listings didn't match the idea; resale sellers (Mercari, eBay resellers) unlabelled.
